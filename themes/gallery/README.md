# Windows Bar theme gallery

These JSON files use the same partial-token format as user themes. Copy any
theme JSON into `%APPDATA%\Windows Bar\themes\`, then choose it in Settings →
Appearance. Windows Bar ignores unknown keys and falls back to the default
theme for invalid colors or numeric values.

Color values accept `#rrggbb`, `#rrggbbaa`, or RGB/RGBA arrays. Available
tokens are `panel`, `glass`, `border`, `card`, `text`, `muted`, `button`,
`accent`, `radius`, `panel_radius`, `font`, `spacing`, and `blur`.
