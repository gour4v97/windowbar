# Localization workflow

Windows Bar has a runtime translation loader (`core/i18n.py`), a language picker in Settings > General, and CI checks for the catalogs. The Settings window, dock menus, popups, launcher, card titles and widget names are routed through `tr()`; text built at runtime (for example weather descriptions or f-strings) is still English. No non-English locale ships yet.

## Translation conventions

- Use English source text as the fallback and stable message key for the initial rollout.
- Keep translation files in `locales/<locale>.json`, encoded as UTF-8 JSON objects.
- Keep placeholders identical between English and translated values (for example, `{count}`). Do not concatenate sentence fragments to build a sentence.
- Use standard locale tags such as `en`, `en-GB`, or `hi`; do not add a locale until a maintainer can review it.
- Preserve Windows product names, keyboard shortcuts, paths, and code tokens unless a translator's note says otherwise.
- Record pluralization and formatting requirements before translating dynamic messages. Avoid inventing a plural rule in a flat key/value file.

## Contribution and review

1. Include a translator note for ambiguous UI context.
2. Review strings in the UI for clipping, mnemonic conflicts, and correct keyboard shortcut rendering.

To add a string: write it as `tr("English text")` in the UI code, then run `python scripts/extract_strings.py --write` to refresh `locales/en.json` (CI fails if it is stale). To add a language, copy `en.json` to `locales/<tag>.json`, translate the values, and run `python scripts/check_locales.py`.

## Release localization checklist

- [x] Choose and document the runtime localization approach (small in-house loader, `core/i18n.py`).
- [x] Add an English source catalog (`locales/en.json`, generated by `scripts/extract_strings.py`).
- [x] Add locale selection and fallback behavior in Settings/config (`language` key; restart to apply).
- [x] Add key parity, JSON syntax, placeholder and catalog-freshness checks to CI.
- [x] Route the static UI (dock menus, popups, launcher, card titles) through `tr()`.
- [ ] Route runtime-built strings (f-strings, service messages) through `tr()` with placeholders.
- [ ] Complete a native-speaker review before advertising a locale as supported.
